1) Open the notebook in Google Colab
============================================================
- Use the Open in Colab badge in the notebook, or open Colab and upload the .ipynb file.

============================================================
2) Create the named secret key in Colab
============================================================
Do these steps before running notebook cells:

1. In Colab, click the key icon in the left sidebar (Secrets).
2. Click Add new secret.
3. Name the secret exactly: OPENAI_API_KEY
4. Paste the key value in the Value field.
5. Turn Notebook access ON for this secret.

Important:
- Keep this key private.
- Do not paste the key into notebook code cells.
- Do not commit the key to GitHub.
